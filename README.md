# GRPS MTSS Field Manual

A practical guide to Multi-Tiered System of Supports at GRPS: find the right support for a scholar, group, or school; decide who should respond; build or review a plan; and run an MTSS meeting.

**Live site:** https://melatkins2-ops.github.io/grps-mtss-field-manual-review/

## What's here

- `index.html`: the whole manual (Framework, Find the Right Support, Academic, Attendance/Behavior/SEL, SST & Teams, Build a Plan, Tools)

## Good to know

- Covers academics, attendance, behavior/PBIS, and SEL/mental health as one connected system.

## Updating the site

Edit the files on a branch and open a pull request. GitHub Pages publishes `main` automatically, usually within a minute or two of a merge.

## Automated site check

Every pull request and every push to `main` runs **Site check** (`.github/workflows/site-check.yml`). It opens the site in a headless browser at desktop (1366px) and phone (390px) widths and fails if the page throws a JavaScript error, a local file or image is missing, or the page scrolls sideways. See the Actions tab for results.
